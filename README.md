# Neurodynamics_Project
## Period Doubling Route to Chaos

This project investigates how a dynamical system transitions from periodic behaviour to chaos.

### Research Question

How does a dynamical system transition from periodic behaviour to chaos?

### Method

The logistic map is simulated for different values of the control parameter \(r\). A bifurcation diagram is used to investigate the period-doubling cascade. The distances between bifurcation points are calculated and their ratios are compared with the theoretical Feigenbaum constant.

### Results

The simulation shows a sequence of period-doubling bifurcations. The calculated Feigenbaum ratios are approximately 4.70, 4.75, and 4.59, which are close to the theoretical Feigenbaum constant of approximately 4.669.
